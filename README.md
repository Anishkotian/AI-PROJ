# Save The Villain
Run (from this folder):  python -m http.server 8000   then open http://localhost:8000
(or use the VS Code "Live Server" extension). Double-clicking index.html will NOT work (ES modules).

Controls: arrows/WASD move | 1/2/3 pick Trap/Obstacle/Door, click a tile in range | E = End Turn
Tuning: all level numbers (countdown, resources, trap delay, health) are in js/levels.js
